# OpenTelemetry instrumentation for ClickStack. We use the VANILLA OTel distro
# rather than the ClickStack docs' hyperdx-opentelemetry package: that package
# hard-pins opentelemetry-api==1.30.0, which conflicts with the Langfuse SDK v4
# used by the chat feature (Langfuse requires opentelemetry-api>=1.33.1). The
# ClickStack collector accepts standard OTLP, so vanilla behaves identically.
# All four are pinned to one consistent release line (core 1.43.0 /
# instrumentation 0.64b0). opentelemetry-distro provides the opentelemetry-bootstrap
# and opentelemetry-instrument entry points, and `opentelemetry-bootstrap -a install`
# (run in the Dockerfile) adds any remaining auto-detected instrumentations at the
# same line. FastAPI + logging instrumentation are pinned explicitly so traces and
# log correlation are deterministic. Import-guarded in app/observability.py, so the
# app still runs if these are absent.
opentelemetry-distro==0.64b0
opentelemetry-exporter-otlp==1.43.0
opentelemetry-instrumentation-fastapi==0.64b0
opentelemetry-instrumentation-logging==0.64b0
