# Recovery evidence

Named resets are implemented by `fixtures/checkpoints/`. `agent/episodes/near_expiry.json` is labeled synthetic teaching evidence; the frontend's fixed API fixtures are local browser-test data. Neither bundle is a recorded managed Cloud execution.

Before a public session, save a redacted decision export, snapshot/source revision evidence, receipt-price next sale, benchmark manifest, and correlated ClickStack IDs from the dedicated Cloud rehearsal. Keep generation and ingestion mode with every export. Add verified immutable download links to the release record only after publication. Do not import a recorded receipt into a learner's live pricing ledger.

Actual Cloud recovery exports remain an open release gate. The kit can restore scenarios and retry delivery, but a checkpoint cannot provision services or replace missing connector/data access.
